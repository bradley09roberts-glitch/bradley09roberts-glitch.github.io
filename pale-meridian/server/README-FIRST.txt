PALE MERIDIAN - SERVER PACKAGE
==============================

This folder becomes a private Minecraft Java 26.2 server running the Pale Meridian story.

Windows:  double-click install-server.bat, read the EULA note it prints, then start-server.bat
Linux:    ./install-server.sh   then   ./start-server.sh

Nothing starts until YOU accept the Minecraft EULA by editing eula.txt yourself.
Whitelist is on: add each friend with   whitelist add <Name>   in the server console.

Full guide (ports, backups, updates, troubleshooting): SERVER_GUIDE.md
