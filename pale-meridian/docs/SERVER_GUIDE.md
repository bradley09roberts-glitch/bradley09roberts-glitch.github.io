# Pale Meridian — Server Guide

A private server lets 2–4 friends play the campaign together. Everything here is spoiler-free.
If you only want to play alone, you do not need a server: see `QUICKSTART.md`.

---

## 1. What you need

| | |
|---|---|
| Computer | Windows 10/11 (primary) or Linux. 4 GB free RAM for the server (2 GB minimum), 3 GB disk. |
| Java | **Java 25 or newer.** Eclipse Temurin 25 (https://adoptium.net) is a good free choice. |
| Package | `PaleMeridian-Server-1.0.0.zip` from `dist/`. |
| Players | Everyone needs Minecraft: Java Edition **26.2** with the **Pale Meridian 1.0.0** client pack. |

The package contains only this project's own files. Minecraft's server software, the Fabric loader
and the third-party mods are downloaded by the installer from their official sources and each file
is checked against a pinned hash before it is used.

---

## 2. Install (Windows)

1. Unzip the package into a **new, empty folder**, e.g. `C:\PaleMeridianServer`. Never unzip it over
   an existing server or a Minecraft installation.
2. Double-click **`install-server.bat`**. It checks Java, downloads and verifies the files, and
   creates `server.properties` and `eula.txt` (with `eula=false`).
   - Windows may say the file came from the internet. The `.bat` runs PowerShell with
     `-ExecutionPolicy Bypass` **for that one process only**; no system setting is changed.
3. **The Minecraft EULA — your decision.** Read https://aka.ms/MinecraftEULA. If you agree, open
   `eula.txt` in Notepad and change `eula=false` to `eula=true`, then save. Nothing in this package
   changes that line for you, and the server will not start until you do.
4. Double-click **`start-server.bat`**. The first start downloads Minecraft's server files and builds
   the valley; wait until the console says `Done`.
5. In the server console, add each player (including yourself):
   ```
   whitelist add YourName
   whitelist add FriendName
   ```
   Optionally make the host an operator (needed for the admin tools below): `op YourName`.
6. To stop the server, type `stop` in the console (this saves the world).

## 3. Install (Linux)

```bash
unzip PaleMeridian-Server-1.0.0.zip && cd PaleMeridian-Server-1.0.0
./install-server.sh            # add --with-tools for Chunky and spark (optional)
nano eula.txt                  # after reading https://aka.ms/MinecraftEULA, set eula=true yourself
./start-server.sh              # PM_MAX_RAM=6G ./start-server.sh to give it more memory
```
To keep it running after you log out, start it inside `tmux` or `screen`.

## 4. Connecting

- **Same computer:** in Minecraft → Multiplayer → Add Server → address `localhost`.
- **Same home network:** use the server computer's local IP address (e.g. `192.168.1.20`).
  When Java first opens the port, Windows Firewall may ask for permission: allowing it on
  **Private networks** is enough for home play. This package never changes firewall or router settings.
- **Friends elsewhere:** that is your decision and your network. Two common options:
  a private overlay/VPN network you control, or forwarding TCP port 25565 on your router to the
  server computer. The defaults below (official account login + enforced whitelist) are designed so
  that only people you add can join either way.

## 5. Security defaults (in `server.properties.template`)

| Setting | Value | Why |
|---|---|---|
| `online-mode` | `true` | Players must log in with real Microsoft/Minecraft accounts. Keep it on. |
| `white-list`, `enforce-whitelist` | `true` | Only players you add can join. |
| `enable-rcon`, `enable-query`, `management-server-enabled` | `false` | No remote administration ports are opened. No passwords are stored anywhere. |
| `spawn-protection` | `0` | Lets every player (not just operators) build near spawn, where the story starts. |
| `max-players` | `4` | The campaign is designed and balanced for 1–4 players. |
| `level-type` | `minecraft:normal` | Must stay the default: the valley is generated by the Pale Meridian mod. |

An existing `server.properties` is never overwritten; the template is copied only on first install.
PvP between players is switched off by the campaign (game rule `pvp`); an operator can turn it back on with `/gamerule minecraft:pvp true`.

## 6. Playing together

- Story progress belongs to the **world**: when anyone completes a step, it is complete for everyone.
  Each player keeps their own journal, inventory and settings.
- Players who join late get a short recap and their journal fills in automatically.
- Encounters scale with the number of players present; nobody is ever required to be online.
- **World settings** (the fog's chill, keep-inventory, encounter difficulty) are in the Field
  Journal → Comfort settings. On a server, an operator can run `/function palemeridian:admin/host`
  to become the only person allowed to change them.

## 7. Admin and recovery tools (operators only)

| Command | What it does |
|---|---|
| `/pmadmin status` | Is this a valley world? Restored districts, running background jobs, save schema, chapter. |
| `/pmadmin relift <district>` | Re-applies a restored district's clear sky/biomes to loaded chunks (districts: landing, hollin, aldercross, glassworks, deepcut, mere, fen, wilds). |
| `/function palemeridian:admin/status` | Every quest's state (0 locked, 1 active, 2 done). |
| `/function palemeridian:admin/refresh` | Non-destructive repair: re-runs quest activation, objective marker, NPC placement and journals. **Try this first.** |
| `/function palemeridian:admin/reset_encounters` | Stops and resets any running encounter (it restarts when a player walks back in). |
| `/function palemeridian:admin/force {q:"<quest id>"}` | Last resort: marks a stuck quest complete and runs its rewards. Quest ids are shown by `admin/status`. |
| `/function palemeridian:admin/goto {poi:"<name>"}` | Teleports you to a named story location (names: `tools/generated/poi.json` in the source). |

Every story step has a built-in recovery path (supplies refill, broken puzzle parts repair themselves,
lost key items can be recovered), so `admin/force` should rarely be needed.

## 8. Backups

Stop the server first (type `stop`), then run **`backup-world.bat`** (Windows) or
**`./backup-world.sh`** (Linux). Backups go to `backups/` with a timestamp; the newest 10 are kept.
The scripts refuse to run while the server is running.

**Restore:** stop the server, move the current `world` folder aside (don't delete it yet), unpack
the backup into the server folder so that `world` is back, start the server.

## 9. Updating and rolling back

1. Stop the server and make a backup.
2. Unzip the new server package into a **separate** folder.
3. Windows: `powershell -NoProfile -ExecutionPolicy Bypass -File update-server.ps1 -NewPackage C:\path\to\new`
   Linux: `./update-server.sh /path/to/new`
4. The old `mods` folder is kept in `backups/mods-<time>`. **Rollback:** stop the server, put that
   folder back as `mods`, and restore the world backup from step 1 if the new version changed it.

The world, `server.properties`, whitelist, operators and `eula.txt` are never replaced by an update.
Save data carries a schema number; a newer version upgrades older saves automatically, and an older
version refuses nothing but warns operators if it opens a world saved by a newer one.

## 10. Performance

- Defaults: view distance 10, simulation distance 8. On a small machine use 8/6.
- Optional: install with `--with-tools` / `-WithTools` and pre-generate the valley once so first
  exploration is smooth: `chunky center 0 0`, `chunky radius 600`, `chunky start` (in the console).
- `spark` (also optional) can profile lag: `/spark profiler start`, then `/spark profiler stop`.

## 11. Troubleshooting

| Symptom | Fix |
|---|---|
| "The Minecraft EULA has not been accepted" | Read the EULA and edit `eula.txt` yourself (step 3). |
| "Java 25 or newer is required" | Install Java 25 and make sure `java -version` in a new terminal shows 25. |
| "hash mismatch" during install | A download was corrupted or changed upstream. Nothing was installed; try again later. Never bypass the check. |
| Red message: world not created with the Default world type | The world was made with another world type. Stop, move `world` aside, and start again with `level-type=minecraft\:normal`. |
| Friends can't join: "not whitelisted" | `whitelist add TheirName` in the console. |
| Friends can't join: version/mod mismatch | Everyone must use the same Pale Meridian client pack version (1.0.0) on Minecraft 26.2. |
| Port already in use | Another server is running; stop it or change `server-port`. |
