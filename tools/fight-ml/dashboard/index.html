Rewarded for every right pick

The RL agent picks a fighter, scores +1 when that fighter wins and −1 when they lose, and shifts its weights toward whatever earned reward (policy gradient). It explores by picking each side in proportion to its belief, so its own picks land a little below its best guesses.

Does it beat the closing line?

The model gate: log loss against the de-vigged close on the same bouts, with a 95% bootstrap interval. A model clears it only if the whole interval is right of zero.

Log loss advantage over the close

Close's log loss minus the model's, per bout. Right of zero beats the market. A model far off the scale is drawn at the edge with its value.
