# Visual backlog (models and polish, to do at the end)

A running list of everything that would look better with its own 3D model or more modelling work. Items stay
2D on purpose (flat Terraria-style icons, held facing left), so this list is about creatures, bosses, NPCs,
blocks, projectiles and effects. Each new stage adds its entries under **Future** and moves them up once built.

Priority: **A** = very visible / looks clearly wrong today, **B** = noticeable, **C** = nice to have.
