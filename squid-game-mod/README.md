# Squid Game: The Tournament - a Minecraft Java Edition mod

A complete, playable *Squid Game* style tournament for Minecraft Java Edition (Fabric, 1.21.1): a custom dimension with a
dormitory, guard corridors, the stairway maze, a control room and **six hand-built arenas**; up to hundreds of **numbered NPC
contestants** in green tracksuits, each with their own face, personality and memory; masked guards; a giant animated doll; and
six games - **Red Light, Green Light, Dalgona, Tug of War, Marbles, the Glass Bridge and the Final Squid Game** - played in
order, elimination after elimination, until one winner takes the prize. Play alone among NPCs or together with other players
mixed with NPCs. Everything is server-authoritative and works in single-player (integrated server) and on a dedicated server.

> This project is a fan-made tribute for private play. It is not affiliated with or endorsed by the creators of the series.
> All models, textures, sounds and structures are generated by the scripts in `tools/` (original work, no copied assets).

## Requirements

| Component | Version |
|-----------|---------|
| Minecraft Java Edition | **1.21.1** |
| Mod loader | **Fabric Loader 0.16.10 or newer** (compiled against 0.19.3; the dedicated-server runs used 0.17.3, the client runs 0.19.3) |
| Required mods | **Fabric API 0.116.17+1.21.1**, **GeckoLib 4.9.3** (`geckolib-fabric-1.21.1`) |
| Java | **21** (build and run) |
| Mappings (build) | Mojang official mappings (Fabric Loom 1.17.21, Gradle 9.5.1 wrapper) |

1.21.1 is the newest release for which Fabric API, GeckoLib's classic `GeoEntity` animation API and the tooling were all stable
together when the mod was built. The source set is split (`src/main` common, `src/client` client only), so no client class can
leak into a dedicated server.

## Install

The `dist/` folder of this repository is a ready bundle (rebuild it with `tools/package.sh`):

```
dist/mods/squidgame-1.0.0.jar                      this mod
dist/mods/fabric-api-0.116.17+1.21.1.jar           Fabric API (Apache-2.0, from maven.fabricmc.net)
dist/mods/geckolib-fabric-1.21.1-4.9.3.jar         GeckoLib (MIT, from the GeckoLib Maven repository)
dist/SHA256SUMS, dist/INSTALL.txt
```

1. Install Java 21 and Fabric Loader for Minecraft 1.21.1 (https://fabricmc.net/use/).
2. Copy the three jars into the `mods` folder of your game (single-player) **and** of your server; every player on a server
   needs the same three files.
3. A dedicated server needs `eula=true` in `eula.txt`: you have to accept the Minecraft EULA (https://aka.ms/MinecraftEULA)
   yourself, nothing in this bundle does that for you.
4. Start the game or server. The mod creates `config/squidgame.json` on first start.

Single-player note: Minecraft treats every world with more than the three vanilla dimensions as "experimental" and asks for a
confirmation each time the world is opened. The complex lives in a fourth dimension, so a small optional client mixin skips that
prompt when the arena dimension is the only reason (it never hides a prompt caused by experimental feature packs). If the mixin
cannot be applied on your setup the vanilla prompt simply appears: choose "I know what I'm doing!" - nothing is at risk.

## Quick start

* **Single-player**: create or open any world, then run `/squid enter` (no permissions needed) - or craft a **Recruiter's Card**
  (paper + pink dye + black dye, shapeless) and right-click it. The first time, the dormitory is generated (about 15 s) and
  you are teleported in; the six arenas are generated when the first tournament starts (about 30 s more, with progress messages).
  Right-click the **registration terminal** (or the card, or `/squid join`) to become a contestant; the tournament starts when
  the registration countdown ends. `/squid start` opens one at once, `/squid start hard 60` chooses the difficulty and the number of
  NPCs (default: 100 contestants in total).
* **Multiplayer**: the same; every player who registers becomes a numbered contestant among the NPCs. Players who arrive while a
  tournament is running spectate; a player who disconnects is replaced by an AI stand-in with the same number and takes the body
  back on return (after `disconnectGraceSeconds` the contestant is eliminated).
* **Only watching**: `/squid debug simulate 100` (op) runs a complete NPC-only tournament you can follow from the control room.
* **Explore**: when no tournament runs, the six gates at the top of the stairway hall (or `/squid arena red_light` ...) take you
  to the arenas.
* **Leave / reset**: `/squid leave` returns you to where you came from (inventory, gamemode, position restored);
  `/squid reset` (op) aborts the tournament and cleans the complex up.

## How a tournament runs

`Lobby -> registration -> instructions (waiting room, rules read out) -> countdown -> game -> eliminations -> results ->
night in the dormitory -> next game -> ... -> final winner -> restart`.

* Every contestant keeps their number, personality and status for the whole tournament; the eliminated stay out (humans become
  spectators and can follow the rest, e.g. from the control room); the prize pool in the giant piggy bank grows with every
  elimination (100,000,000 W per elimination).
* The games are played in the canonical order. A game the remaining field is too small for is skipped and announced (Tug of War
  and the Glass Bridge need 4 contestants; a bridge field of 11 or fewer is shown the first rows of the bridge up front, so
  that somebody can still get across); with two contestants left the tournament goes straight to the Final, which always leaves
  exactly one winner (a knockout ladder of duels when more than two reach it).
* If nobody survives a game the tournament ends without a winner; ties and timeouts have defined rules per game
  (`docs/games/*.md`).
* A typical default tournament (100 contestants, Normal) narrows 100 -> ~80 -> ~70 -> ~35 -> ~17 -> ~8 -> 1 and takes about
  25 minutes (23 minutes measured in a real-time NPC-only run, registration to the winner).

## The six games and their controls

Full rules, difficulty tables, NPC behaviour and controls of every game are in `docs/games/`. Key bindings can be changed under
*Options -> Controls -> Squid Game*; the instructions shown in-game always print the real bound keys.

| # | Game (arena) | What happens | Controls |
|---|--------------|--------------|----------|
| 1 | [Red Light, Green Light](docs/games/red_light.md) (sun-bleached playground, giant tree) | cross 130 blocks while the doll chants; when she turns you have a short *stopping allowance*, then **eyes lit = any movement you cause eliminates you**; judged server-side with the same rules for humans and NPCs | walk / sprint / jump; just stop when her eyes glow |
| 2 | [Dalgona](docs/games/dalgona.md) (old school hall, 160 seats) | pick a blind honeycomb tin (circle, triangle, star or the dreaded umbrella) and carve the shape out without cracking it; licks relieve stress | click or `1`-`4` to pick the tin; hold **left mouse** and trace the groove; **right mouse** or `L` licks; `Esc` steps away, right-click the desk to come back |
| 3 | [Tug of War](docs/games/tug_of_war.md) (steel hall, two platforms over a pit) | balanced teams, stamina, a shared rhythm to heave on, bracing; the team that is pulled over its edge falls | hold `R` pull, tap `F` on the beat (heave), hold `Left Shift` brace |
| 4 | [Marbles](docs/games/marbles.md) (night-time village) | pick a partner, then win their marbles: odd-or-even wagering, or the target throw (`marblesVariant`) | right-click a contestant to partner up; panel: `-`/`+`, `Odd`/`Even`, Lock in (`M` reopens it); throw: aim, hold **right mouse** to charge, release |
| 5 | [Glass Bridge](docs/games/glass_bridge.md) (vast dark hall, 18 rows of glass) | contestants are called one by one in a random order; one panel per row holds, the other shatters; the route is hidden and retained, NPCs learn only from what they see; small fields are shown the first rows | walk / sprint / jump across the gaps; a row map overlay shows only what everybody has seen |
| 6 | [Final Squid Game](docs/games/final.md) (sunset playground, the white squid) | attacker vs defender on the squid court: stamina based combat, win by taking the circle, a knockout or the clock; more than two finalists play a knockout ladder | **left mouse** light strike, hold + release heavy strike, hold **right mouse** guard (parry window), `V` or double-tap `A`/`D`/`S` dodge, `G` shove |

Difficulty (`Normal / Hard / Extreme`) tightens timings, shrinks tolerances and allowances, scarcifies resources and makes the NPCs
better; it is chosen with `/squid start <difficulty>` or the `defaultDifficulty` option.

## Commands

All under `/squid`. Commands without a permission note work for every player (also in single-player without cheats).

| Command | Who | Effect |
|---------|-----|--------|
| `enter` / `leave` | anyone | go to the complex (generated on first use) / return home |
| `start [normal\|hard\|extreme] [npcs]` | anyone (when none runs) | open registration (you are registered), optional difficulty and number of NPCs |
| `join` / `spectate` / `status` | anyone | register (registration phase) / watch / show the state |
| `arena <name>` | anyone (no tournament running) | free tour of an arena: `red_light dalgona tug_of_war marbles glass_bridge final hub` |
| `skip` | op | skip the current phase (registration, countdown, game ...) |
| `reset [home]` | op | abort and clean up (optionally send everyone home) |
| `build [force]` | op | (re)generate the complex |
| `config [key [value]]` | op | read / change options live |
| `debug simulate [npcs] [difficulty]` | op | NPC-only tournament |
| `debug play <game> [npcs] [difficulty]` | op | exactly one game, with you as a contestant (`red_light dalgona tug_of_war marbles glass_bridge final`) |
| `debug playopen <game> [npcs] [difficulty]` | op | like `play`, but registration stays open so other players can `/squid join` (`/squid skip` ends it) |
| `debug perf` | op | the built-in profiler (manager, game logic, HUD, NPC entities, NPC behaviours, whole tick) |
| `debug rules <player>` | op | why a player is (not) restricted by the arena rules |
| `debug timescale <x>`, `debug eliminate <n>`, `debug roster`, `debug markers <arena>`, `debug builders` | op | test helpers |

## Configuration

`config/squidgame.json` (created with the defaults on first start) or live with `/squid config <key> <value>`.

| Key | Default | Meaning |
|-----|---------|---------|
| `totalContestants` | 100 | contestants in total (humans + NPCs); NPCs fill up to this number |
| `npcCount` | -1 | if >= 0, exactly this many NPCs regardless of the number of players |
| `maxContestants` | 128 | cap (2 - 456); the arenas are sized for 128, more works (see Performance) |
| `defaultDifficulty` | `normal` | `normal`, `hard`, `extreme` |
| `registrationSeconds` / `instructionSeconds` / `countdownSeconds` | 30 / 22 / 5 | phase lengths |
| `resultsSeconds` / `transitionSeconds` / `winnerSeconds` / `restartDelaySeconds` | 14 / 30 / 25 / 15 | phase lengths |
| `timeScale` | 1.0 | multiplies every phase and game timer (0.2 = five times faster, handy for testing) |
| `autoRestart` | false | start a fresh registration automatically after a tournament (servers) |
| `lateJoinSpectate` | true | players joining mid-tournament spectate (false = sent home) |
| `disconnectGraceSeconds` | 90 | how long an absent contestant's AI stand-in plays on before the contestant is eliminated |
| `resumeOnRestart` | true | after a server restart resume the tournament at the start of the interrupted game (false = reset) |
| `spectateAfterElimination` | true | eliminated humans keep spectating until the end (false = sent home after the results) |
| `buildBlocksPerTick` / `buildMillisPerTick` | 8000 / 14 | generation speed versus tick budget |
| `autoBuildOnEnter` | true | generate the dormitory the first time somebody enters |
| `enforceRules` | true | restrict contestants inside the complex (see below) |
| `allowOpsToBypassRules` | true | operators in creative mode are not restricted |
| `marblesVariant` | `mixed` | `mixed`, `odd_even`, `throw` |
| `npcFarDistance` / `npcFarTickInterval` | 80 / 3 | NPCs farther than this from every human decide only every n-th tick (movement stays smooth) |
| `debug` | false | verbose debug lines in the server log |

## Rules inside the arenas

While you are in the complex your gamemode, inventory, health, effects, position and respawn point are snapshotted and restored
when you leave. Contestants cannot build, break, fly, teleport (any jump the mod did not cause is undone), use ender pearls,
chorus fruit, fireworks or tridents, change equipment, open containers (chests, furnaces, crafting tables ...) or stay outside
the arena bounds while a game runs (a warning, then they are put back, and after about eight seconds outside they are
eliminated); vanilla damage is cancelled so
only the games decide who is out. Operators in creative mode may bypass the rules (`allowOpsToBypassRules`). Respawns happen
in the dormitory. The tournament state (roster, numbers, personalities, statuses, the hidden glass bridge route ...) is saved
with the world: after a server restart the interrupted game replays from its start (or the tournament resets,
`resumeOnRestart`).

## Difficulty

| | Normal | Hard | Extreme |
|--|--------|------|---------|
| Red Light: stopping allowance / time to cross | 1.1 s / 200 s | 0.65 s / 185 s | 0.3 s / 165 s |
| Dalgona: time (tin selection included) | 150 s | tighter, more fragile shapes | shortest |
| Tug of War: time per heat | 100 s | 85 s | 70 s |
| Marbles: marbles each / game time | 10 / 210 s | 8 / 180 s | 5 / 150 s |
| Glass Bridge: stall limit / time (small crowd) | 25 s / 330 s | 18 s / 270 s | 12 s / 210 s |
| Final: duel time | 180 s | 150 s | 120 s |

Each game's document has the complete table. The NPC populations scale with the difficulty too (measured with 100 NPCs: Red
Light survivors about 80 % / 63 % / 42 %, Dalgona 85 % / 68 % / 44 %, Glass Bridge crowd crossing 85 % / 48 % / 22 %).

## Performance

Measured with `/squid debug perf` on a shared 4-vCPU container (other test servers and a software-rendered client were running
at the same time, so real hardware should do better). Whole server tick, Red Light on the field:

| NPCs | NPC entity ticks | whole tick (average / worst) |
|------|------------------|------------------------------|
| 40 | 0.7 ms | 4.8 ms |
| 128 | 3.2 ms | 6.3 / 13.7 ms |
| 456 | 11.4 ms | 15.4 / 35.3 ms (budget 50 ms) |

The game logic and the NPC behaviours stay below 1 ms in every game (128 NPCs: Dalgona 2.0 - 2.4 ms per tick in total, Tug of
War 4.9 ms, Glass Bridge 1.4 - 2 ms for the entities). NPCs far from every human decide less often (`npcFarDistance`,
`npcFarTickInterval`) while their movement stays continuous. Building: the dormitory (1.17 M blocks) takes about 12 s, all six
arenas together about 30 s, spread over ticks so the server stays responsive.

## Building from source and developer tools

```
./gradlew build              # compiles, runs the unit tests, produces build/libs/squidgame-1.0.0.jar
tools/package.sh             # build + assemble dist/ (mod jar, dependency jars, SHA256SUMS, INSTALL.txt)
./gradlew runServer          # dev server (set eula=true yourself)
tools/devserver.sh restart   # Maven-bootstrapped dedicated server in run-server/ (SQUID_ACCEPT_EULA=1 writes eula.txt: that is YOU accepting the EULA)
tools/smoke.sh 100 normal    # full NPC-only tournament at 100 ticks/s; fails on server errors
tools/xvfb-client.sh         # headless (Xvfb + llvmpipe) test client joining the dev server; screenshots with `import -window root x.png`
tools/spclient.sh            # headless single-player client (integrated server) in run-spclient/
tools/xinput.py / rcon.py    # scripted mouse+keyboard input for the headless client / RCON for the dev server
```

Developer documentation: `docs/ARCHITECTURE.md` (layers, lifecycle, how to add a game), `docs/ARENA_MARKERS.md` (arena contract),
`docs/ASSET_CONTRACT.md` (models, animations, sounds), `docs/BUILDING_GUIDE.md` (structure DSL and previews), `docs/games/*.md`
(per game: rules, controls, difficulty, NPC behaviour, networking, verification, limitations). Assets and arenas are generated by
`tools/assets/**` and `src/main/java/com/squidgame/build/**`; they are previewable without launching Minecraft (`tools/dump.sh`,
`tools/preview.py`).
