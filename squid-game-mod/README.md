# Squid Game: The Tournament - a Minecraft Java Edition mod

A complete, playable *Squid Game* style tournament for Minecraft Java Edition: a custom dimension with a dormitory, guard
corridors, the stairway maze, a control room and **six hand-built arenas**; up to hundreds of **numbered NPC contestants** in
green tracksuits with their own faces, personalities and memories; masked guards; a giant animated doll; and six games -
**Red Light, Green Light, Dalgona, Tug of War, Marbles, the Glass Bridge and the Final Squid Game** - played in order,
elimination after elimination, until one winner takes the prize. Play alone among NPCs, or together with other players mixed
with NPCs. Everything is server-authoritative, works on a dedicated server and in single-player.

> This project is a fan-made tribute for private play. It is not affiliated with or endorsed by the creators of the series.
> All models, textures, sounds and structures are generated by the scripts in `tools/` (original work, no copied assets).

## Stack (chosen and verified)

| Component | Version |
|-----------|---------|
| Minecraft Java Edition | **1.21.1** |
| Mod loader | **Fabric Loader 0.16.10 or newer** (built and tested with 0.19.3) |
| Required mods | **Fabric API 0.116.17+1.21.1**, **GeckoLib 4.9.3** (`geckolib-fabric-1.21.1`) |
| Java | **21** (build and run) |
| Mappings | Mojang official mappings (Fabric Loom 1.17.21, Gradle 9.5.1 wrapper) |

Why this combination: 1.21.1 is the newest release for which Fabric API, GeckoLib's classic `GeoEntity` animation API and the
tooling are all stable together; the newest Minecraft versions were rejected because their API surface for the required libraries
could not be verified. The source set is split (`src/main` common, `src/client` client only), so no client class can leak into
a dedicated server.

## Install

1. Install Java 21 and Fabric Loader for Minecraft 1.21.1 (https://fabricmc.net/use/).
2. Put these three files in the `mods` folder (client **and** server; on a server all clients need the same mods):
   * `squidgame-1.0.0.jar` (this mod; in `dist/` after a build, or `build/libs/`)
   * `fabric-api-0.116.17+1.21.1.jar` (Modrinth / CurseForge)
   * `geckolib-fabric-1.21.1-4.9.3.jar` (https://modrinth.com/mod/geckolib)
3. Start the game / server. A server needs `eula=true` (you must accept the Minecraft EULA yourself).

## Quick start

* **Single-player**: create or open any world, then run `/squid enter` (no permissions needed) - or craft a **Recruiter's Card**
  (paper + pink dye + black dye, shapeless) and right-click it. The first time, the complex is generated in the background
  (about half a minute, with progress messages) and you are teleported into the dormitory. Right-click the **registration
  terminal** (or the card, or `/squid join`) to register as a contestant; the tournament starts when the registration
  countdown ends (`/squid start` starts one immediately; `/squid start hard 60` = difficulty and number of NPCs).
* **Multiplayer**: the same, every player who registers becomes a numbered contestant among the NPCs. Players who arrive while a
  tournament is running spectate; a player who disconnects is replaced by an AI stand-in with the same number and takes the body
  back on return (after `disconnectGraceSeconds` they are eliminated).
* **Only watching**: `/squid debug simulate 40` runs a complete NPC-only tournament you can follow from the control room.
* **Reset / leave**: `/squid leave` returns you to where you came from (inventory, gamemode, position restored);
  `/squid reset` aborts the tournament and cleans the complex up.

## What happens in a tournament

`Lobby -> registration -> instructions (waiting room, rules read out) -> countdown -> game -> eliminations -> results ->
night in the dormitory -> next game -> ... -> final winner -> restart`. Every contestant keeps their number, personality and
status all the way; the eliminated stay out (humans become spectators and can follow the rest from the control room); the prize
pool in the giant piggy bank grows with every elimination. If nobody survives a game the tournament ends without a winner; if two
are left the final is played; ties and timeouts have defined rules per game. See `docs/games/*.md` for the exact rules, difficulty
tables, controls and NPC behaviour of each game:

| # | Game | Arena | Summary |
|---|------|-------|---------|
| 1 | [Red Light, Green Light](docs/games/red_light.md) | sun-bleached playground with a giant tree | cross the field, freeze when her eyes glow; movement is judged server-side with a clearly explained stopping allowance |
| 2 | [Dalgona](docs/games/dalgona.md) | warm old school hall, 160 seats | trace circle / triangle / star / umbrella out of the honeycomb without cracking it; licks, needle speed and fragile corners matter |
| 3 | [Tug of War](docs/games/tug_of_war.md) | steel hall with two high platforms over a pit | balanced teams, stamina, a shared rhythm to heave on, bracing; the losing team falls |
| 4 | [Marbles](docs/games/marbles.md) | night-time village of alleys | pair up, then win your partner's marbles: odd-or-even wagering or target throwing |
| 5 | [Glass Bridge](docs/games/glass_bridge.md) | vast dark hall, 18 rows of glass | one panel per row holds; a hidden route that is learned only from what is seen |
| 6 | [Final Squid Game](docs/games/final.md) | sunset playground with the white squid | attacker vs defender, stamina based combat, win by the circle, a knock-out or the clock |

Difficulty (`Normal / Hard / Extreme`) tightens timings, shrinks tolerances and allowances, scarcifies resources and makes the NPCs
better; it is chosen with `/squid start <difficulty>` or the `defaultDifficulty` option.

## Commands (all under `/squid`)

| Command | Who | Effect |
|---------|-----|--------|
| `enter` / `leave` | anyone | go to the complex (generated on first use) / return home |
| `start [normal\|hard\|extreme] [npcs]` | anyone (when none runs) | open registration (you are registered), optional difficulty and NPC count |
| `join` / `spectate` / `status` | anyone | register / watch / show state |
| `arena <name>` | anyone (no tournament running) | free tour of an arena: `red_light dalgona tug_of_war marbles glass_bridge final hub` |
| `skip` | op | skip the current phase (registration, countdown, game...) |
| `reset [home]` | op | abort and clean up (optionally send everyone home) |
| `build [force]` | op | (re)generate the complex |
| `config [key [value]]` | op | read / change options |
| `debug simulate [npcs] [difficulty]` | op | NPC-only tournament |
| `debug play <game> [npcs] [difficulty]` | op | exactly one game, with you as a contestant |
| `debug timescale <x>`, `debug eliminate <n>`, `debug roster`, `debug markers <arena>`, `debug builders`, `debug perf` | op | test helpers; `perf` prints the built-in profiler |

## Configuration (`config/squidgame.json`, or `/squid config <key> <value>` live)

`totalContestants` (default 40) / `npcCount` (-1 = fill up to `totalContestants`) / `maxContestants` (128; up to 456 works but
see the performance notes), `defaultDifficulty`, phase lengths (`registrationSeconds`, `instructionSeconds`, `countdownSeconds`,
`resultsSeconds`, `transitionSeconds`, `winnerSeconds`, `restartDelaySeconds`), `timeScale` (multiplies every duration),
`autoRestart`, `lateJoinSpectate`, `disconnectGraceSeconds`, `resumeOnRestart`, `spectateAfterElimination`,
`buildBlocksPerTick` / `buildMillisPerTick` (generation speed vs tick budget), `autoBuildOnEnter`, `enforceRules`,
`allowOpsToBypassRules`, `marblesVariant` (`odd_even`, `throw`, `mixed`), `npcFarDistance` / `npcFarTickInterval` (NPC level of
detail), `debug`.

## Rules inside the arenas

While you are in the complex your gamemode, inventory, health, effects, position and respawn point are snapshotted and restored
when you leave. Contestants cannot build, break, fly, teleport, use ender pearls or chorus fruit, change equipment, open containers
or leave the arena bounds (operators may bypass with `allowOpsToBypassRules`); damage is cancelled so only the game decides who
is out. Respawns happen in the dormitory. The tournament state (roster, numbers, personalities, statuses, the hidden glass bridge
route ...) is saved with the world: after a server restart the interrupted round restarts cleanly (or the tournament resets,
`resumeOnRestart`).

## Building from source

```
./gradlew build            # compiles, runs the unit tests, produces build/libs/squidgame-1.0.0.jar
./gradlew runServer        # dev server (set eula=true yourself)
tools/devserver.sh restart # alternative: Maven-bootstrapped dedicated server in run-server/ (SQUID_ACCEPT_EULA=1 accepts the EULA)
```

Developer documentation: `docs/ARCHITECTURE.md` (layers, lifecycle, how to add a game), `docs/ARENA_MARKERS.md` (arena contract),
`docs/ASSET_CONTRACT.md` (models, animations, sounds), `docs/BUILDING_GUIDE.md` (structure DSL and previews). Assets and arenas are
generated by `tools/assets/**` and `src/main/java/com/squidgame/build/**`; they are previewable without launching Minecraft
(`tools/dump.sh`, `tools/preview.py`).
